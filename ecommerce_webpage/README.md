# E-commerce Webpage

A React + Vite demo with React Router and four pages: Home, About, Contact, and Product.

## Run locally

1. Extract the ZIP.
2. Open the extracted `ecommerce_webpage` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the localhost URL printed in the terminal (usually http://localhost:5173).

## Routes

- `/` — Home
- `/about` — About
- `/contact` — Contact form demo
- `/product` — Product listing

Product data is stored in `public/products.json`. Product images currently use online placeholder URLs, so an internet connection is needed to display them.
The contact form and Buy Now buttons are demo interactions only; no backend or payment processing is configured.
